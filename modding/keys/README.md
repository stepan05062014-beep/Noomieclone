# Ключ подписи

`debug-key.pem` / `debug-cert.pem` / `debug-key.p12` — **одна и та же одноразовая
локальная пара ключей**, которой подписан `NoomiClone-modded.apk` в корне репозитория.

* Это не секрет и не чей-то настоящий ключ: сертификат самоподписанный,
  `CN=NoomiClone Mod`, выпущен только для сайдлоада собственного мода.
* Ключ лежит в репозитории специально: Android разрешает установку комплекта
  base + сплиты и обновление приложения **только если сертификат совпадает**.
  Пересборка этим ключом даёт файлы, совместимые с уже установленной версией мода.
* Отпечаток сертификата (SHA-256):
  `3b3538d726fd7a98b53e8a2635b00596be8a69c8ee372b4f92b200728c6f5ce6`

## Что чем подписывать

| Файл | Кто понимает |
|---|---|
| `debug-key.pem` + `debug-cert.pem` | `noomi_visual.py`, `apksign.py`, `build_installable.py` |
| `debug-key.p12` | MT Manager, KeyStore Explorer, `apksigner --ks ... --ks-type PKCS12` |

Параметры для `.p12`: **alias `noomi`**, **пароль `noomi`**.

Для настоящего проекта/публикации нужен свой ключ (`keytool`), который хранят
приватно — этот для того не годится.
