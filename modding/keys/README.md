# Ключ подписи

`debug-key.pem` / `debug-cert.pem` — **одноразовая локальная пара ключей**, которой
подписан `NoomiClone-modded.apk` в корне репозитория.

* Это не секрет и не чей-то настоящий ключ: сертификат самоподписанный,
  `CN=NoomiClone Mod`, выпущен только для сайдлоада собственного мода.
* Ключ лежит в репозитории специально: Android разрешает обновление приложения
  поверх старого **только если подпись совпадает**. С этим ключом пересборка
  `python modding/noomi_visual.py apply ...` даст файл, который встанет поверх
  предыдущей версии мода без удаления.
* Отпечаток сертификата (SHA-256):
  `3b3538d726fd7a98b53e8a2635b00596be8a69c8ee372b4f92b200728c6f5ce6`
* Для настоящего проекта/публикации нужен свой ключ (`keytool` или
  `apksigner`, хранить приватно) — этот для того не годится.
